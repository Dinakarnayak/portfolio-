# Dinakar Nayak — Portfolio

A responsive personal portfolio for AI engineering, software development and selected projects.

## Stack
- React 19 + TypeScript
- Vite 7 for development and production builds
- Lucide icons and custom responsive CSS
- Vitest for project-data and filtering tests
- GitHub Actions for continuous validation

## Getting started

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm test
npm run build
```

Project cards, category filters and skill groups live in `src/data/portfolio.ts`.
